B. Updates
------------------------
* Enhanced Notifications 
  - Updates repeated auto-pickup ON/OFF notifications in place instead of stacking them as separate entries.

* Show Summon Counter
  - Added support for Spirit Caller animal summons.
  - Skeleton and animal summons are counted separately and displayed vertically when both are active.
  - Added unique animal summon icons for all three UI styles.
  - Both counters share the existing visibility, position, scale and animation settings.
  - Only counters with active summons are displayed.

* Enemy Detector
  - Added a new SplitDeepNorth mode to distinguish lesser Deep North enemies from regular enemies.
  - Frozen Greydwarfs, Frozen Greydwarf Shamans and Deep North Skeletons are counted separately as lesser enemies.
  - Added unique single-claw icons for all three UI styles, matching the existing enemy icons.
  - The lesser enemy counter supports both display modes, both rail positions and existing animations.
  - Consolidated and standard Split modes remain unchanged.
  - Refactored enemy detection logic into EnemyDetectorLogic, separating detection logic from UI rendering.

* Biome-Sorted Crafting Tabs
  - The last selected crafting tab is now retained when switching between crafting stations, opening chests or switching between Craft and Upgrade.
  - Automatically falls back to the All tab when the remembered category is unavailable at the current station.
  - Restores the previously selected tab when its category becomes available again.
  - Supports both Multiple Rows and Scrolling modes.
