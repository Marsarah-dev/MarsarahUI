IMPLEMENTED - NOT RELEASED
============================================================

A. Standalone Mod / Architecture
--------------------------------
* Created standalone MarsarahUI and removed the UI module from MarsarahTweaks.
* Removed the old/alternate UI layout system and kept the preferred layout only.
* Added ServerSync with a master Enable Server Overrides option.
* Added admin overrides to 10 gameplay/information-oriented features:
  - Enemy Detector
  - Current Day
  - Current Time
  - Weather Forecast
  - Smart Biome
  - Ashlands Heat Meter
  - Enemy Nameplate Mode
  - Taming Progress
  - Detailed Hover Information
  - Container Contents
* All other UI settings remain local player preferences.
* Added lightweight CompatibilityManager integration for:
  - MarsarahTweaks
  - Craft From Containers
  - Minimal Status Effects
* Smart Biome accounts for Tweaks Gear Upgrade Unlock when Tweaks is installed.
